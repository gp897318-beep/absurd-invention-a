One-sentence absurd invention pitch for @g290: a laundry basket that holds
one sock hostage from every load and only returns it once you have folded
the rest, so the clean laundry finally gets folded instead of living in
the basket forever. The program writes exactly that one sentence (193
characters) to `/output/entry.txt` and nothing else, then reads it back
and checks it against the gate (1–220 characters, one sentence).

## Run it

```sh
node main.ts
```
